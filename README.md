# Bravo

Bravo is a real-time multiplayer competitive coding platform.

## Planned Features

- Team-based coding battles
- Ranked 1v1 matchmaking
- Multiplayer coding contests
- Secure code judging with Judge0 CE
- Live leaderboards
- ML-based judge worker autoscaling
- Plagiarism detection
- Post-match AI reports

## Technology Stack

- Node.js 20, Express and JavaScript
- React, Vite and Tailwind CSS
- MongoDB and Mongoose
- Redis and Socket.io
- Judge0 CE
- Python, FastAPI and XGBoost
- Prometheus and Grafana
- Docker Compose
