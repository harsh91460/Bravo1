# Bravo Architecture

## Frontend
React, Vite, Tailwind CSS and Monaco Editor.

## Backend
Node.js, Express, Socket.io and Zod.

## Data
MongoDB for persistent data.
Redis for presence, queues and realtime scaling.

## Code Execution
Judge0 CE executes submitted code in its sandbox.

## Monitoring
Prometheus collects metrics.
Grafana visualizes metrics.

## ML Services
FastAPI provides forecasting and anomaly detection.
SmartScale manages judge worker scaling.
